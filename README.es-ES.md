# Coronavirus - Rio Grande do Sul

Hola, este repositorio está destinado a presentar estadísticas del Coronavirus en Rio Grande do Sul de forma fácil y amigable.

Todos los datos presentados son recuperados a partir de la API Pública [Covid19 Brazil API](https://covid19-brazil-api-docs.now.sh/), la misma se actualiza hora tras hora con datos proporcionados por el [Governo do Brasil](https://saude.gov.br).

## Pré-requisitos

- Yarn >= 1.13.0
- Node >= 10.16.1

## Cómo instalar

Necesitarás clonar el repositorio:

```
git clone git@github.com:leonardorpr/coronavirus-rs.git
cd coronavirus-rs/
```

Con el repositorio en mano, solo debes instalar las dependencias:

```
yarn install
```

## Cómo ejecutar

```
yarn start
```

## Cómo contribuir

Solo tienes que hacer un Fork de este repositorio, realizar tus modificaciones y luego enviar un Pull Request aquí (:
